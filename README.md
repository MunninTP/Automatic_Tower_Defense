# Automatic_Tower_Defense
An automatic tower defense written in C 
Nom du projet : Tower defense automatisé
IDE utilisée : codeblocks (le projet fonctionne uniquement à travers cette IDE)
Bibliothèque utilisée pour l'affichage : SDL
But : Un tower defense qui place les tours automatiquement selon un algorithme qui cherche le "meilleur emplacement" par rapport au chemin : des ennemies apparaîssent aléatoirement au début du chemin et avance sur le chemin jusqu'à la tour du Roi. A des intervalles égaux, des vagues d'ennemies apparaîssent.
